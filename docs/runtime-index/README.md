# Runtime Index Subsystem

The **Runtime Index Subsystem** powers local hybrid search across all computer artifacts and text assets.

## Indexed Entities
- PDFs
- Documents (DOCX, Markdown, TXT)
- Downloads
- Screenshots
- OCR Results
- Browser Pages
- Execution Reports
- Clipboard Snippets

## Search Capabilities
- **Keyword Scoring**: BM25-style frequency scoring with title boost.
- **Semantic Matching**: Cosine similarity against local vector embeddings.
- **Filtering**: By entity type, tags, and date ranges.
- **Zero Cloud**: 100% local execution.
